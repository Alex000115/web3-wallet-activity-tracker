# Web3 Wallet Activity Tracker

A beginner-friendly Web3 project that allows users to track blockchain wallet activity, token balances, and recent transactions using public blockchain APIs.

This repository is designed to look professional, clean, and easy to understand while teaching core Web3 concepts such as wallet tracking, API usage, and blockchain data parsing.

---

## Features

- Track any public crypto wallet address
- View token balances
- View recent blockchain transactions
- Simple web interface
- Uses public blockchain API
- Clean and beginner-friendly code

---

## Tech Stack

- HTML
- CSS
- JavaScript
- Public Blockchain API (Etherscan or similar)

---

## How It Works

1. User enters a wallet address
2. App sends a request to a blockchain API
3. API returns wallet data
4. App displays balances and transactions in a simple dashboard
